### ⭐ Featured project: Tracewell, an error-monitoring platform

A self-hostable, Sentry-style platform: services report errors over a signed API, and teams search, triage, and investigate them in a web dashboard.

| | |
|---|---|
| **[Observability-Platform](https://github.com/UmangSachdeva/Observability-Platform)** · Go, MongoDB | Ingestion API with **HMAC-SHA256 signed requests** and **project-scoped API keys**; error search with filters, sorting, and **keyset (cursor) pagination**; JWT authentication; accounts, roles, and invitations. |
| **[Observability-Platform-frontend](https://github.com/UmangSachdeva/Observability-Platform-frontend)** · Next.js 16, React 19 | Dashboard with **⌘K account-wide search**, error detail pages with **stack traces parsed for 5 languages**, occurrence analytics, a guided integration flow, and **silent session renewal** behind a backend-for-frontend layer. |
